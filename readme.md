# BoardGameStats

BoardGameStats - веб-приложение для учета личной статистики по настольным играм.

Проект позволяет пользователю зарегистрироваться, добавлять результаты сыгранных партий и смотреть базовую статистику по каждой игре: количество побед, ничьих, поражений, максимальный, минимальный и средний счет.


Проект выполнен в качестве школьного проекта в 2021 году.

## Функции

### Пользователи

- Регистрация по имени, email, паролю.
- Авторизация по email и паролю.
- Выход из аккаунта.
- Страница личного кабинета с базовой информацией о пользователе.

### Записи о партиях

- Добавление новой партии.
- Указание названия игры.
- Указание счета.
- Выбор результата: победа, ничья или поражение.

### Статистика

- Просмотр списка игр, по которым у пользователя есть записи.
- Выбор игры для просмотра статистики.
- Подсчет:
  - количества побед;
  - количества ничьих;
  - количества поражений;
  - максимального счета;
  - минимального счета;
  - среднего счета.

### API

В проекте есть простое API для получения записей о партиях.

Доступные эндпоинты:

```text
GET /api/matches
GET /api/matches/<user_id>
```

`/api/matches` возвращает все партии.

`/api/matches/<user_id>` возвращает партии конкретного пользователя.

### Ключевые файлы

- `main.py` - основной Flask-файл с маршрутами приложения.
- `data/db_session.py` - настройка подключения к базе данных.
- `data/users.py` - модель пользователя.
- `data/games.py` - модель игры.
- `data/matches.py` - модель партии.
- `api/matches_api.py` - JSON API для партий.
- `templates/` - HTML-шаблоны страниц.
- `static/` - стили и изображения.
- `db/matches.db` - локальная SQLite-база данных, создается и используется локально, не хранится в репозитории.

## Запуск

1. Создать и активировать виртуальное окружение.

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
```

Linux/macOS:

```bash
source .venv/bin/activate
```

2. Установить зависимости.

```bash
pip install -r requirements.txt
```

3. Запустить приложение.

```bash
python main.py
```

Для локального запуска приложение использует запасной ключ `dev-secret-key`. Для публикации или деплоя задайте переменную окружения `SECRET_KEY`.

После запуска приложение будет доступно по адресу:

```text
http://127.0.0.1:5000
```
